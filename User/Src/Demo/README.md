# Demo：阶段性任务（8 字轨迹）

> ⚠️ **本目录不属于最终产品架构。**
> 它只为完成一个阶段性交付：让车按固定剧本跑出「直走 → 右弧 → 直走 → 左弧」的 8 字轨迹。
> **最终巡线 / 竞速成品不需要这里的任何代码**，做完即可整目录删除。

---

## 一、为什么单独放一个目录

最终产品是「摄像头巡线 + 竞速」，控制链应该是：

```
视觉/循迹层 → 目标速度 + 目标角速度 → 转向环 + 速度环 → 直立环 → 电机
```

上面的每一环都由**传感器反馈**决定目标量。

而本 demo 的目标量来自**一张写死的表格**（第几秒该多快、往哪拐）。
它没有反馈、不能应变，纯粹是为了演示。**这种「开环剧本」一旦混进正式控制层，
以后做循迹时会分不清「这个目标量是视觉给的还是剧本给的」。**

所以：**代码隔离在 `Demo/`，主控制层只暴露一个通用入口 `Control_SetTarget()`，
对 demo 的存在一无所知。**

## 二、边界（硬约束）

### 2.1 Demo 可以依赖什么

| 依赖 | 用途 |
|---|---|
| `Control_SetTarget(speed, yaw_rate, steer)` | **唯一输出口**，下目标量 |
| `Attitude_IsUpright()` / `Attitude_IsCalibrating()` | 摔倒/标定中中止 |
| `car_run`（`event.h`） | 启停阶段，作触发边沿 |
| `HAL_GetTick()` | 段计时 |

### 2.2 Demo 绝不可以

- ❌ 直接调 `motor_drive()` —— 绕过限幅、死区补偿和所有安全联锁
- ❌ 直接写 `Control.c` / `Control_PID.c` 的内部状态
- ❌ 被 `Control` / `Attitude` / `Telemetry` 反向依赖
- ❌ 注册 HAL 回调（`HAL_TIM_PeriodElapsedCallback` 等全局弱函数）
- ❌ 在中断里做耗时操作（`Demo_Update()` 跑在 TIM7 1 kHz 里）

### 2.3 调用点只有一个

`User/Src/event.c` 的 TIM7 分支：

```c
else if (htim == &htim7)
{
    Attitude_Update();
#if (DEMO_ENABLE)
    Demo_Update();          /* ← 必须在 Control_Update() 之前：先下目标，再算输出 */
#endif
    Control_Update();
}
```

顺序不能反：`Demo_Update()` 只负责**给目标**，`Control_Update()` 才**算输出**。

## 三、剧本设计

### 3.1 运行方式

**上电不会自动跑**，流程与蜂鸣器启动音同构：

```
上电（车静止不动）
  → 按 KEY0 停车（car_run 1→0）
  → 再按 KEY0 启动（car_run 0→1）→ 剧本开始
  → 跑完 / 中途再按 KEY0 → 停
```

实现靠 `car_run` 的 0→1 上升沿（`s_armed` 初值 = `car_run`，所以上电不触发）。

### 3.2 段落定义

```c
typedef struct {
    float    speed;       /* 目标速度，计数/2ms（不换算 m/s） */
    float    steer;       /* 开环差速量，PWM 计数；0 = 直行 */
    float    yaw_target;  /* 闭环目标角速度 rad/s；需 yaw 验证通过后启用 */
    uint16_t duration_ms; /* 本段时长 */
    bool     use_angle;   /* true = 按转过角度切段（覆盖 duration） */
    float    turn_deg;    /* 本段要转过的角度，正 = 右 */
} DemoStep;
```

**每段两个终止条件，取先满足的**：

| 条件 | 说明 |
|---|---|
| `duration_ms` 到时 | 简单，但受速度波动影响 |
| `use_angle` 且 `\|∫yaw_rate·dt\| ≥ turn_deg` | **8 字对称的关键** |

角度制让两条弧转过的角度相同 —— 即使两段速度略有差异，轨迹也不会越跑越歪。
yaw 零偏约 0.01 rad/s，10 s 才漂 5.7°，短剧本完全够用。

### 3.3 剧本表（起点值，必须实测改）

| 段 | 作用 | speed | steer | duration | use_angle | turn_deg |
|---|---|---|---|---|---|---|
| 1 | 直走进入 | +8 | 0 | 2000 ms | ✗ | — |
| 2 | **右弧** | +5 | **+80** | 4000 ms | ✓ | **+180°** |
| 3 | 直走过渡 | +8 | 0 | 1000 ms | ✗ | — |
| 4 | **左弧** | +5 | **−80** | 4000 ms | ✓ | **−180°** |
| 5 | 直走收尾 | +8 | 0 | 1500 ms | ✗ | — |
| 6 | 停 | 0 | 0 | — | — | — |

两段弧各转 180°，合计回到出发方向 → 轨迹为 **8 字**。

**数值依据：**

| 参数 | 为什么取这个值 |
|---|---|
| `speed = 8` | ≈ 0.62 m/s（按 k_x = 6500 估）；不标 k_x 也能跑 |
| `speed = 5`（弧段） | 降速减小离心力，不易甩倒 |
| `steer = 80` | **必须 > 死区 50**，否则轮子不转、画不出弧 |

### 3.4 转向方案（两选一，切换只改数据）

| 方案 | 怎么给 | 依赖 yaw 验证 | 摔车风险 | 8 字整齐度 |
|---|---|---|---|---|
| **A 开环差速**（先做） | `steer = ±80`（填 `steer` 列） | ❌ 不需要 | **无** | 一般 |
| B yaw 闭环（再升级） | `yaw_target = ±ω`（填 `yaw_target` 列，`steer` 留 0） | ✅ 需要 | 符号错会摔 | 好 |

**先用方案 A 交作品**。方案 B 只在 yaw 轴验证（符号 + 幅值）通过后才启用。

## 四、调参顺序（不要一次全开）

| 步 | 改什么 | 判据 |
|---|---|---|
| 1 | 只留段 1（`speed = 8`），其余段时长设 0 | 直走 2 s 不跑飞、不摔 |
| 2 | 加段 2（`steer = +80`，`duration = 2000`，关 `use_angle`） | 向右画弧，不摔 |
| 3 | 段 2 开 `use_angle`，`turn_deg = 90` | 转到约 90° 就自动切段（目视对照） |
| 4 | 补段 3、4（左弧，`steer = −80`） | 画出 S 形 |
| 5 | 段 2、4 的 `turn_deg` 加到 ±180 | 画出完整 8 字 |

⚠️ **180° 很难一次成功。先用 60~90° 试通**，确认轨迹方向和场地够用，再加大。

### 场地需求

`turn_deg = 180°`、弧长 `v·t = 0.62 × 4 ≈ 2.5 m` → 半径 ≈ 0.79 m
→ **至少 3 m × 2 m 空地**，四周无障碍。测 60° 时场地可减半。

## 五、安全中止

```c
if (!Attitude_IsUpright() || Attitude_IsCalibrating())
{
    demo_abort();   /* 目标全清 0 */
}
```

三条必须：

1. **任何时刻摔倒 → 立即清目标**，不继续转轮子
2. **剧本跑完 → 清目标**，保持直立但不再前进（不自动倒车）
3. **中途按 KEY0 → 清目标并复位剧本索引**

`Control_Update()` 现有的姿态联锁会兜底（`Attitude_IsUpright()` 为假就 `motor_drive(0,0)`），
但 demo 仍应主动清目标 —— 否则联锁解除瞬间会接着跑旧目标。

## 六、验收标准

满足全部 5 条即视为阶段性任务完成：

| # | 判据 | 怎么验 |
|---|---|---|
| 1 | 按 KEY0 后能直走 ≥ 2 s，不跑飞不摔 | 目视 + `wheel_dist` 单调增 |
| 2 | 能画出至少 1 个完整弧（右或左） | 目视轨迹 |
| 3 | 直线 → 右弧 → 直线 → 左弧 四段能连着跑完 | 目视近似 S 形 |
| 4 | 两段弧转向相反、大小接近 | 目视 8 字是否对称 |
| 5 | 摔倒能自动停（不继续转轮） | 故意手推倒测试 |

**不列入验收**（避免自己卡自己）：

- ❌ 8 字精确闭合 —— 开环做不到，yaw 闭环也只能近似
- ❌ 直线完全不跑偏 —— 要差速同步细调，属质量增强
- ❌ 消除直立小幅振动 —— 已有结论：接受它
- ❌ 目标速度用 m/s —— 不标 k_x 也能跑

## 七、怎么完整移除（做完必看）

三处，删干净不留尾巴：

### 7.1 删目录

```
User/Inc/Demo/     ← Demo.h
User/Src/Demo/     ← Demo.c、本 README
```

### 7.2 改 CMakeLists

把这一段整段注释掉或删除（在 `target_sources` 里）：

```cmake
    # 阶段性 Demo：8 字轨迹演练，与最终巡线/竞速无关，做完可整段删除
    User/Src/Demo/Demo.c
```

以及 `target_include_directories` 里的 `User/Inc/Demo`。

### 7.3 改 event.c

```c
#if (DEMO_ENABLE)
    Demo_Update();
#endif
```

改成直接删掉这几行。

### 7.4 检查残留

```
grep -rn "Demo\|DEMO_" User/ Core/ CMakeLists.txt
```

应当只剩 `demo/` 目录自身的引用（且目录已删）。

⚠️ **`Control_SetTarget()` 保留** —— 它不是 demo 专用，最终循迹层也要用它下目标量。
