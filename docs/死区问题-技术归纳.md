# 两轮自平衡车：静摩擦死区导致无法消除的高频振动

> 归纳日期：2026-11-15
> 目的：把「加死区补偿后反而更抖」这个问题完整交给外部专家分析
> 平台：STM32F407 + 有刷直流减速电机（双轮差速）+ LSM6DSR IMU

---

## 一、问题一句话

电机存在约 **5% 占空比的静摩擦死区**。不补偿则小信号无响应、跨阈值时跳变（间断抖）；
补偿则工作在「静止/转动」双稳态边界，形成持续抖（stick-slip 极限环）。
**开环死区前馈在该系统上无法同时消除这两种抖动。**

---

## 二、实测现象（用户报告，全部为实物观测）

| 配置 | 现象 |
|---|---|
| 无死区补偿，KD = 200 | 高频振动（「每次临近平衡点时轮子带动车快速振动」） |
| 无死区补偿，KD = 100~130 | 可较稳定直立 |
| **死区补偿 = 50** | **持续抖，比无补偿时更抖** |
| **死区补偿 = 25 左右（更小）** | **间断地抖（一阵一阵），仍不能消抖** |
| **KD = 50** | **无法平衡**（阻尼不足，站不住） |

用户原话归纳：**「死区大了一直抖，小了间断地抖，无法起到消抖的作用」**

### 死区实测方法

`Control.c` 里临时插入定值输出，绕过 PID 直接给两轮同号 PWM，逐档递增，
以「轮子起转」为判据（用编码器累计值 `wheel_dist` 判定，非目视）：

| 工况 | 起转最小 PWM |
|---|---|
| 悬空（轮子离地） | **40** |
| 地面（整车负载） | **50** |

PWM 量程 0~999（ARR = 1000），故 **d₀ ≈ 5% 占空比**。
差值 10 归因于地面滚动阻力；其余 80% 为减速箱静摩擦。
**已排除 H 桥/驱动器的逻辑死区**（那是几个计数的量级）。
未测滞回（d_停转），这是后续需要补的数据。

### 4.2 姿态融合（互补滤波）

```c
/* User/Src/Attitude.c —— 由 TIM7 以 1 kHz 调用 */
void Attitude_Update(void)
{
    gyro[i] = (float)imu_gyro[i];      /* 读全局快照，主循环刷新，本函数不检查是否为新数据 */
    acc[i]  = (float)imu_acc[i];

    acc_tilt = atan2f(acc[1], acc[2]);         /* 加速度计倾角 */
    s_acc_tilt = acc_tilt;

    gyro_rate = (gyro[0] - s_gyro_bias[0]) * ATTITUDE_GYRO_LSB_TO_RADS;
    s_pitch_rate = gyro_rate;                   /* D 项用的就是它，无任何滤波 */

    diff = acc_tilt - s_pitch;                  /* 归一化到 ±π */
    s_pitch += ATTITUDE_ALPHA * gyro_rate * ATTITUDE_DT_S   /* 0.98 × rate × 1ms */
             + (1.0f - ATTITUDE_ALPHA) * diff;              /* 0.02 × 加速度修正 */
}

#define ATTITUDE_DT_S   0.001f
#define ATTITUDE_ALPHA  0.98f      /* 名义截止 ≈ 3.2 Hz */
```

### 4.3 控制器（串级）

```c
/* User/Src/Control/Control_PID.c —— 1 kHz */
void Control_PID_Step(const Control_Input *in, Control_Output *out)
{
    /* ① 速度环 PI：速度(计数/2ms) → 倾角给定(rad) */
    s_speed_int += in->speed * pid_speed_ki * in->dt;
    s_speed_int  = clamp(s_speed_int, pid_speed_ilim);
    pitch_set    = pid_pitch_trim_rad - (in->speed * pid_speed_kp + s_speed_int);
    pitch_set    = clamp(pitch_set, pid_pitch_set_limit);

    /* ② 直立环 PD：倾角误差 → 推力(PWM 计数) */
    thrust = (in->pitch - pitch_set) * pid_pitch_kp
           +  in->pitch_rate          * pid_pitch_kd;

    /* ③ 转向环 P */
    steer = -in->turn_rate * pid_turn_kp;

    out->left  = thrust + steer;
    out->right = thrust - steer;
}
```

**当前参数：**

| 参数 | 值 | 备注 |
|---|---|---|
| `PID_PITCH_KP` | 3000 | 内环刚度 |
| `PID_PITCH_KD` | 200 | 用户实测 >130 即高频振动 |
| `PID_SPEED_KP` | 0.001 | 明显偏小 |
| `PID_SPEED_KI` | 0.0005 | 明显偏小 |
| `PID_SPEED_ILIM` | 0.05 | 积分限幅（rad） |
| `PID_PITCH_SET_LIMIT` | 0.4 | 倾角给定限幅（22.9°） |
| `PID_PITCH_TRIM_RAD` | -0.06 | 机械中值（平衡点 -3.4°） |
| `PID_TURN_KP` | 0 | 转向环关闭 |

### 4.4 输出级（死区前馈 + 限幅）

```c
/* User/Src/Control/Control.c —— 1 kHz */
static int16_t control_limit(float v)
{
    if (v >  (float)CONTROL_PWM_MAX) v =  (float)CONTROL_PWM_MAX;
    else if (v < -(float)CONTROL_PWM_MAX) v = -(float)CONTROL_PWM_MAX;
    return (int16_t)v;
}

static void control_output(float thrust, float steer, int16_t *left, int16_t *right)
{
    /* 只对共模加偏移；不改变符号 */
    if (thrust > 0.0f)      thrust += (float)CONTROL_DEADZONE;
    else if (thrust < 0.0f) thrust -= (float)CONTROL_DEADZONE;

    *left  = control_limit(thrust + steer);
    *right = control_limit(thrust - steer);
}

#define CONTROL_PWM_MAX  999
#define CONTROL_DEADZONE 50      /* 地面实测起转值；用户已试 0 / 25 / 50 */
```

## 五、数值核算

### 5.1 内环二阶特性

按 $k/h \approx 0.05$、$g/h \approx 98$ 估算（$k$ = 加速度反馈增益，$h$ = 重心高度）：

$$\omega_n = \sqrt{\frac{k}{h}KP - \frac{g}{h}}, \qquad \zeta = \frac{(k/h)\,KD}{2\omega_n}$$

| KP | ωn (rad/s) | 周期 T | KD | ζ |
|---|---|---|---|---|
| 3000 | 7.2 | 0.87 s | 120 | 0.42 |
| 3000 | 7.2 | 0.87 s | **200** | **0.70** |
| 3000 | 7.2 | 0.87 s | 50 | 0.17 |

**关键矛盾**：按此模型 KD = 200 已足够阻尼（ζ = 0.70），实测却高频振动。
**说明模型没有覆盖真正的失稳机理**，或者说模型里的 $k/h$ 估算不准（未实测验证）。

### 5.2 死区换算成「误差盲区」

死区 $d_0 = 50$ 计数，KP = 3000：

$$\text{盲区} = \frac{d_0}{KP} = 0.0167\ \text{rad} = \mathbf{0.96°}$$

D 项要单独跨越死区所需的角速度：

$$\dot{\theta} = \frac{50}{200} = 0.25\ \text{rad/s} = \mathbf{14.3°/s}$$

**含义**：摆速低于 14°/s 时，D 项完全不贡献阻尼。

### 5.3 高频段 D 项与 P 项的相对强弱

设结构/噪声引起的角振动 $A = 0.2°$、频率 $f$：

| f | ω (rad/s) | rate = ωA (rad/s) | D 项 = 200×rate | P 项 = 3000×A | D/P |
|---|---|---|---|---|---|
| 3 Hz | 18.8 | 0.066 | 13 | 10.5 | 1.3 |
| 10 Hz | 62.8 | 0.219 | 44 | 10.5 | 4.2 |
| 30 Hz | 188 | 0.658 | **132** | 10.5 | **12.6** |
| 100 Hz | 628 | 2.19 | 439 | 10.5 | 42 |

**D 项在高频段主导**。D 项本身相位超前，一旦回路中存在延迟或柔性，超前会翻转为激励。

### 5.4 陀螺噪声折算

假设噪声密度 4 mdps/√Hz、LPF 212 Hz（等效噪声带宽 ≈ 333 Hz）：

$$\theta_{n,\text{rms}} \approx 4 \times \sqrt{333} \approx 73\ \text{mdps} = 1.27\times10^{-3}\ \text{rad/s}$$

$KD = 200$ 时 → 输出噪声 $0.25$ 计数，**可忽略**。

> 结论：**噪声放大不是抖动来源**。抖动频率与幅度都远大于噪声折算值。

## 六、机理分析

### 6.1 死区的两种响应形态（解释「大了抖、小了也抖」）

死区补偿的形式是 $u_{out} = u + d_0\,\mathrm{sign}(u)$，理论上使有效力矩 $T \propto u$（完全线性）。
但实物存在两个非线性，前馈无法同时处理：

**(a) 补偿量 < 实际死区（用户试的 25）**
```
|u| < 25        → 输出 < 50 → 轮子完全不动  → 环路增益 = 0（无响应）
|u| 越过 25     → 输出跨过 50 → 突然起转    → 阶跃输入
```
→ **bang-bang 式间断抖动**，与用户观察一致。

**(b) 补偿量 ≈ 实际死区（用户试的 50）**
```
u ≈ 0（静止，thrust ≈ 0 因 TRIM 已对齐）
→ 输出 ±50 → 轮子被顶在「静摩擦极限」
→ 噪声使 u 穿越 0 → 输出在 +50 / −50 之间反复翻转
→ 两个模式动力学完全不同：
     静止：轮子锁死，车体 = 固定支点单摆（高刚度）
     转动：轮子自由，车体 = 移动倒立摆（低刚度）
→ 在两模式间往复 = stick-slip 极限环
```
→ **持续抖动**，与用户观察一致。且抖动频率由「起转所需时间」决定，
而非由控制环决定（典型 10~30 Hz）。

**这是本次问题的核心**：`d_0 = 50` 是**实测的起转阈值**，
用它做等值前馈，等于把工作点精确顶在双稳态临界点上。

### 6.1.1 补偿前后的「小信号增益」对比

死区不只是「有个盲区」，它是一个**非线性增益**：

| \|thrust\| | 补偿前 实际力矩 ∝ | 补偿后 实际力矩 ∝ |
|---|---|---|
| 0 | 0（PWM=0，电机不通电） | **±50 → 临界，随机起转** |
| 10 | 0（10 < 50，轮子不动） | 10（完全线性） |
| 30 | 0（轮子不动） | 30（完全线性） |
| 60 | 10（60 − 50） | 60（完全线性） |

**补偿把 0~50 区间的增益从 0 拉到满值**。这在理论上正是我们想要的，
但它同时移除了死区一直充当的「噪声低通」作用：

- 补偿前：pitch 上 ±0.1° 的抖动 → thrust = ±3 → 被死区吞掉 → 轮子零响应
- 补偿后：同样的抖动 → 输出 ±53 → **完整传到轮子**

即噪声传递路径的增益从 0 变成 1，**放大了 100 倍以上**（相对于原来的 0）。

### 6.1.2 关键困境：不存在能满足所有工况的常数 d₀

实测与计算表明死区**不是一个常数**，而是随工况漂移：

| 影响因素 | 变化量 | 依据 |
|---|---|---|
| 负载（悬空 / 地面） | 40 → 50（**+25%**） | 实测 |
| 母线电压 12.6 → 11.1 V | 50 → 57（+14%） | $d_0 \propto 1/V$ |
| 减速箱脂温（冷/热） | 未知，同类系统可达 ±30~50% | 无实测 |
| 前进 / 后退 | 未知（H 桥与齿隙不对称） | **未测** |
| 左轮 / 右轮 | 未知（同类系统典型差 5~10%） | **未测** |
| 电池衰减 / 机械磨损 | 长期漂移 | — |

**因此：任何固定的 `CONTROL_DEADZONE` 必然在两端的某些工况下失配。**

- 取大值（50）→ 在低温/低电量等 d₀ 更大的工况下仍偏小（残盲区）；
  在 d₀ 更小的工况下过量（双稳态抖）
- 取小值（25~30）→ 大部分工况下留下残盲区（间断抖）

**这解释了用户「大了抖、小了也抖」的观察：不是补偿量没调对，而是开环常数补偿这个工具本身不适用。**

若要走前馈路线，则需要 **在线辨识 d₀**（例如利用「给定 PWM 却检测不到转动」这一条件
持续修正估计值），而不是取一次实测常数。

### 6.2 一个被忽略的结构性问题：IMU 数据链的周期性断流

`imu_service()` 在**主循环**里刷新快照，而 `Attitude_Update()` 在 **1 kHz 中断**里消费。
`Attitude_Update()` **不检查 `imu_seq`**，即不判断快照是否为新数据：

```c
/* 现状：每 1 ms 无条件用当前快照积分 */
s_pitch += 0.98f * gyro_rate * 0.001f + 0.02f * diff;
```

而主循环里有一处阻塞发送：`Telemetry_Update()` 以 100 Hz 调用
`uart_send()` → `HAL_UART_Transmit()` 发 42 B：

$$t_{block} = \frac{42 \times 10}{115200} = 3.65\ \text{ms} \quad\text{每 10 ms 发生一次} \quad\Rightarrow\quad \mathbf{36.5\%}\ \text{时间被阻塞}$$

**准确的推论（更正一版草稿里的错误说法）：**

1. 主循环是紧循环，绝大多数轮次在几 µs 内完成 → `imu_service()` 调用非常频繁
2. 但每 10 ms 中有 **3.65 ms 完全不执行**（阻塞在 UART）
3. 这 3.65 ms 内 IMU ODR = 1.66 kHz 会产生 **约 6 个样本**，
   而 DRDY 标志只是单个 `uint8_t` → **6 个样本被合并成 1 个，丢 5 个**
4. `Attitude_Update()` 仍以 1 kHz 消费 → 在空白期**重复使用同一快照**（ZOH）

**这不是「积分倍率错」**：ZOH 保持本身是正确的，若角速度确实不变则积分量正确。
真正的问题是**采样信息丢失 + 周期性延迟抖动**：

| 频段 | 3.65 ms 停顿造成的相位滞后 | D 项（本身超前 90°）剩余有效超前 |
|---|---|---|
| 10 Hz | 13.1° | 76.9°（仍是阻尼） |
| 20 Hz | 26.2° | 63.8°（仍是阻尼） |
| 30 Hz | 39.4° | **50.6°（阻尼被削弱 44%）** |
| 68 Hz | 89.3° | 0.7°（阻尼归零） |
| 100 Hz | 131.2° | **−41.2°（翻转为激励）** |

**结论（修正后）**：这个缺陷**不足以单独解释 10~30 Hz 的抖动**（该频段 D 项仍具阻尼性），
但它有两个确定的副作用：

1. **削弱 D 项的有效阻尼**：30 Hz 时只剩 56% 的有效超前 → 相同 KD 下阻尼效果打折扣
2. **使 KD 的实测上限偏低**：68 Hz 以上 D 项翻转成激励，任何高频结构谐振都会被 KD 放大

因此它会**污染所有调参结论**，建议在继续调参前先修（见 §8.2 方案 E）。

> ⚠️ **待验证**：该推论基于代码静态分析，尚未实测主循环周期与 `imu_seq` 增长率。
> 验证方法见 §8.1。

### 6.3 补充观察

- **TRIM = -0.06 rad**：静止时 `thrust` 真值为 0，即工作点正好停在
  「死区补偿输出 ±50 反复翻转」的最不利位置。
- **PWM = 0 是滑行不是刹车**：`motor_drive(0,0)` 后轮子靠自身转动惯量滑行，
  这使「停止」这一状态的动力学也不确定。
- **速度环增益明显偏小**：$KI_{phys} = KI \cdot k_x/500 = 0.0065$、
  $\omega_{o} = 0.25$ rad/s（时间常数 16 s）。重心偏 0.01 rad 会漂 1.5 m。
  但这是「逐渐跑」的问题，与本次抖动无关。

## 八、需要专家判断的问题

### 8.1 请先验证的测量（我方可以立刻做）

1. **主循环最大停顿**：`DWT->CYCCNT` 标记循环首尾取最大值，或翻转 GPIO 用示波器看最坏间隔
2. **`imu_seq` 增长率**：在遥测帧里加一列 `imu_seq`，其与 1 kHz 的比值即为真实消费比例
3. **抖动频率**：`pitch` 波形做 FFT（遥测 100 Hz 采样，可分辨 ≤50 Hz）
4. **死区滞回**：从大往小降，记 d_停转，与 d_起转(50) 的差值
5. **静止时 `pwm_common` 波形**：确认是否在 ±50 之间翻转（验证 §6.1(b)）

### 8.2 请专家裁决的路线选择

| 方案 | 思路 | 我方顾虑 |
|---|---|---|
| **A. Dither（抖动注入）** | 输出叠加高频小幅三角波（200~500 Hz），使轮子永不进入静摩擦态，等效消除死区 | 14 kHz PWM、1 kHz 控制环能否合成有效的 200~500 Hz dither？会不会加剧噪声？ |
| **B. 部分前馈 + 积分** | d₀ 取 60~70% 的实测值（如 30~35），残余死区交给速度/姿态积分吸收 | 积分项在死区内同样失效（增益 0），是否真能吸收？ |
| **C. 提高 PWM 分辨率** | ARR 从 1000 提到 4000，PWM 频率降到 3.5 kHz | 只提高分辨率不改变相对死区比例；且降低 PWM 频率可能引入电流断续 |
| **D. 加电流/速度内环** | 用编码器做速度内环，死区在环内被高增益淹没 | 低速时编码器量化（0.5 计数/2 ms）分辨率不足，内环增益受限 |
| **E. 先修 §6.2 的时序问题** | 把 IMU 读取移入 1 kHz 定时中断，或给 `Attitude_Update` 加 `imu_seq` 门控 | **我方倾向先做这个**：这是纯软件缺陷，与死区无关，但会污染所有调参结论 |
| **F. 硬件改造** | 换低减速比/低摩擦减速箱，或提高母线电压 | 成本与周期 |
