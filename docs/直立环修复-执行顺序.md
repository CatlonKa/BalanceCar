## 0. 先纠正上一轮的一条推论（影响后面所有判断）

`HANDOFF-balance-2026-11-16b.md` §3.2(c) 说「加速时 `acc_tilt = 0`，
把 `pitch` 拽向 0，产生 272 PWM 假前进推力」。**这条错了**，错在把机械中值当成了 0。

平衡车满足 $a = g\tan(\theta-\theta_0)$，代入比力公式：

$$\tan(\text{tilt}) = \frac{g\sin\theta - a\cos\theta}{g\cos\theta + a\sin\theta}
= \frac{\sin\theta\cos(\theta-\theta_0) - \sin(\theta-\theta_0)\cos\theta}
       {\cos\theta\cos(\theta-\theta_0) + \sin(\theta-\theta_0)\sin\theta}
= \frac{\sin\theta_0}{\cos\theta_0} = \tan\theta_0$$

即 **`acc_tilt` 在持续加减速时恒等于 θ₀ = trim，与加速度大小、方向都无关**。
只有 θ₀ = 0 时才退化成「报 0」。静止实测也是 θ₀（`pitch=-0.0906`, `acc_tilt=-0.0911`）。

真正的后果不是「假推力」，而是更隐蔽的一条：

> **加计在运动中不提供任何 lean 信息**，它把 pitch 估计钉在 trim 上，
> 正好抹掉控制器唯一需要的量 $\theta_p = \theta - \theta_0$。

推论（都对得上用户实测）：
- α 越小 → 加计权重越大 → lean 被抹得越快 → 越迟钝（α=0.98 时「抗扰动差」）
- α 越大 → 越跟手，但绝对参考变慢（α=0.998 时「找平衡点更慢」，τ=0.5 s）

**所以「调 α」治不好，它是两个坏处之间的折中。真正的解法是让加计在运动中重新可用：**
把 $a\cos\theta$ 从 `acc[1]` 里扣掉（`ATTITUDE_LIN_ACC_ENABLE`），扣对之后
`acc_tilt` 重新等于真实 `pitch`，α 才可以放心降到 0.99。

## 1. 另外两条结构性缺陷（与加计无关，独立存在）

### 1.1 速度环 P 通道权限刚好等于需求，零余量

`pitch_set` 相对 trim 的最大偏移 = `pid_speed_err_lim * pid_speed_kp` = 0.04 rad。
平衡车在倾角 θp 下需要的加速度 $a = g\tan\theta_p$：

| θp | 需要的 a | 谁提供 |
|---|---|---|
| 0.04 rad (P 满偏) | **0.39 m/s²** | P 通道刚好 0.39 → **零余量** |
| 0.08 rad（积分满） | 0.79 m/s² | 只能靠积分，而积分时间常数 ≈ 0.33 s |

结论：**瞬间扰动只能靠 0.39 m/s² 去接**，接不住才开始积积分。
这是「被推一下要晃很久才回来」的算术原因。

### 1.2 速度环比直立环还快（串级倒置）

速度环 P 通道的单位换算：`0.002 rad/(计数/2ms)` × 452 (计数/2ms)/(m/s) = **0.905 rad/(m/s)**，
经 $a = g\theta$、$452$ 计数/(m/s) 折算 → 一阶闭环 $\tau = 0.11$ s → **1.41 Hz**。
而直立环 $\omega_n = \sqrt{0.05K_P - 98}$ = 7.2 rad/s = **1.15 Hz**。

串级要求外环 ≤ 内环/3，现在外环**更快** → 速度环会推着姿态环振荡。
若要修：`PID_SPEED_KP` 0.002 → 0.0005，`PID_SPEED_ERR_LIM` 20 → 80（保持 0.04 rad 满偏）。

用户嫌「找平衡点慢」的问题，只能从别处解决（死区、KP），不要再动 α。

#### 「低频抖动」的算术来源（下一步 S5 的依据）

抖动频率 ≈ **1.15 Hz**，正好等于内环固有频率 $\omega_n=\sqrt{0.05K_P-98}$ = 7.2 rad/s。
配合「起转需 50 PWM」这个死区，构成典型的 **stick-slip 极限环**：

```
倾角 < 0.96° → PWM < 50 → 轮子不转 → 车自由倒下（τ=0.10 s）
倾角 > 0.96° → PWM 突然 > 50 → 轮子猛转 → 过冲 → 反向
```

死区角 = 50/KP，**唯一软件解法是抬 KP**（与 `docs/死区问题-技术归纳.md` 结论一致：
开环常数前馈不适用）。

## 5. 闭环极点分析（2026-11-16 第三次修正，以此为准）

> 前两版用相位裕度手算，两次都算错（一次混淆 PWM→加速度增益与 $g\theta$，
> 一次漏了 $K_D$ 项的抵消方向）。本节改为**直接求闭环特征根**，
> 脚本求根结果自带校验（根之和必须等于 $-a$）。

### 模型

$$\ddot\theta = 98\theta - 0.05u,\qquad \dot v = 4430\,\theta
\quad(\text{计数/2ms 每秒})$$

内环 $u=K_P\theta+K_D\dot\theta$，$K_D$ 项在分子里抵消，得
$\theta/\delta = -0.05K_P/(s^2+a s+b)$，$a=0.05K_D$、$b=0.05K_P-98$。

外环 $\delta=-K_{Ps}v$，闭环特征方程：

$$s^3+a s^2+b s+K=0,\qquad K=K_{Ps}\cdot4430\cdot0.05K_P$$

### 根轨迹结果（KP=6000、KD=300）

| $K_{Ps}$ | 振荡极点 | 阻尼 ζ | 行为 | 对应实测 |
|---|---|---|---|---|
| 0.003 | 2.44 Hz | **−0.06** | 发散 | — |
| **0.002（改前）** | **2.19 Hz** | **+0.03** | **等幅振荡** | **「更抖了」** ✓ |
| **0.001（改后）** | **1.94 Hz** | **+0.25** | 1.3 s 内收敛 | — |
| 0.0005 | 1.99 Hz | +0.43 | 最稳，响应慢一倍 | 备选 |

### 旧参数为什么也抖（KP=3000、KD=200、$K_{Ps}$=0.002）

| $K_{Ps}$ | 振荡极点 | ζ |
|---|---|---|
| 0.002 | 1.58 Hz | **−0.17（发散）** |

历史上 KP=3400/KD=200 算出 ζ=−0.15，也是负的。**但车当时确实能站住** ——
说明这个 3 阶线性模型偏保守（忽略了电机反电动势阻尼、轮子惯量、轮地滑移）。
所以：**绝对 ζ 值不可直接采信，只有趋势可用**（ζ 随 $K_{Ps}$ 降而升，
随 $K_P$ 升而升，随 $K_D$ 升而升）。实测现象与该趋势完全一致。

### 结论：抖动的正确旋钮是 $K_{Ps}$，不是 $K_P$

$K_P$ 从 3000 抬到 6000 把振荡从 **1.58 Hz 发散** 变成 **2.19 Hz 等幅**，
是必要的一步（再降回 3000 就回到发散）；但要把等幅振荡压成收敛，
必须降 $K_{Ps}$。

$K_{Ps}$ 从 0.002 降到 0.001 的同时 `ERR_LIM` 从 80 抬到 160，
**$ERR\_LIM\times K_{Ps}=0.16$ rad 不变 → 减速权限一点没少**，只有线性段增益减半。

### α 与环路带宽

加计通路拐点 $f_c=(1-\alpha)/(2\pi\alpha\,dt)$ 必须远低于振荡频率（1.9 Hz）：

| α | $f_c$ | 与 1.9 Hz 比 |
|---|---|---|
| 0.98 | 3.25 Hz | **1.7 倍，已进带内** |
| 0.99 | 1.6 Hz | **0.85 倍，已实测变差** |
| **0.998（现）** | 0.32 Hz | **0.17 倍** ✅ |

历史事实（α=0.98 当年能站住）：那时 `LIN_ACC_ENABLE=0`，加计通路恒为 θ₀
（**直流参考，不含环路振荡**），相位滞后无从作恶。今天 `LIN_ACC_ENABLE=1`，
加计通路承载真实倾角（含振荡），低 α 等于把带滞后的振荡灌回环路。
**α 不是独立旋钮，不要单独调。**

## 6. 「冲出去」的第二个独立机制：积分不清零

`Control_Update()` 的 `!car_run` 分支原来**保留**速度积分。停车时 Control 不跑，
积分冻结在上次顶满的值（±0.08 rad = ±4.6°）。再次按 KEY0 启动 →
`pitch_set` 直接偏 trim 4.6° → 起步瞬间满推力突跳。

**已修**（`Control.c`，一次性）：`!car_run` 分支调 `reset()` 清积分。
